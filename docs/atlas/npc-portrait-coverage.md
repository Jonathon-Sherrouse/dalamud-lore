All 170 previously unpictured character entries have an image. Eleven use in-game textures, including three reused identity slots. The other 159 use bundled portrait references from 157 cropped PNGs. [The source manifest](../../tools/atlas/npc_portraits.json) records each image and its reference page.

Azem has no fixed face in this story and uses Azem?s crystal. Ethos uses the key itself. Azdaja uses her later dragon silhouette in the Growing Light quest illustration. The masked mage and the Watcher retain their hoods. The masked man uses Urianger?s portrait, the white-robed figure uses Fandaniel?s, and the Stormblood voice uses G?raha Tia?s.
