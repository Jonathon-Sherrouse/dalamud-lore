# Agent Task Template

Use this template when assigning work to a specialist agent.

## Title

Short task name

## Story

The owning `NDL-###` story ID

## Goal

One or two sentences describing the user outcome.

## Owner

`runtime` | `dictionary` | `ui` | `content`

## Files In Scope

- `NpcDialogueLinks/...`

## Constraints

- List any boundaries
- Mention files that should not be edited
- Call out any runtime or content requirements
- For content tasks, state whether web research is required and which sources are preferred

## Definition Of Done

- Describe the exact expected result
- Include any notes about tests or in-game verification

## Notes

- Include sample dialogue, terms, or screenshots if relevant
